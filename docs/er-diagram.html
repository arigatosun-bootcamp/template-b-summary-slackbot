ER図 — Summary Slackbot

Supabase上のテーブル構造とリレーションを定義

テーブルリレーション図

テーブル詳細

workspaces — ワークスペース情報

🏢 workspaces
id PK uuid 主キー（自動生成）
team_id NOT NULL text SlackワークスペースID（例: T01ABC123）
team_name text ワークスペース名（例: My Team）
bot_token NOT NULL text Bot User OAuth Token
created_at timestamp 作成日時（デフォルト: now()）
updated_at timestamp 更新日時（デフォルト: now()）

channels — チャンネル情報

💬 channels
id PK uuid 主キー（自動生成）
workspace_id FK uuid → workspaces.id
channel_id NOT NULL text SlackチャンネルID（例: C01ABC123）
channel_name text チャンネル名（例: #general）

summaries — 要約履歴

📝 summaries
id PK uuid 主キー（自動生成）
workspace_id FK uuid → workspaces.id
channel_id FK uuid → channels.id
slack_user_id NOT NULL text SlackユーザーID（例: U01ABC123）
url NOT NULL text 要約対象のURL
title text 記事タイトル
summary NOT NULL text 要約結果
summary_level text 要約レベル（簡単 / 普通 / 詳しく）
llm_provider text 使用したLLM（anthropic / openai）
created_at timestamp 作成日時（デフォルト: now()）

リレーション

1 : N →
workspaces → channels
1つのワークスペースに複数のチャンネルが属する
1 : N →
workspaces → summaries
1つのワークスペースで複数の要約が作成される
1 : N →
channels → summaries
1つのチャンネルで複数の要約が作成される
