# 要件定義書 — Summary Slackbot

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | Summary Slackbot |
| 概要 | URLを入力するとAIが記事を要約し、Slackチャンネルに自動投稿するWebアプリ |
| 対象ユーザー | 長い記事を読む時間がないビジネスパーソン |
| 解決する課題 | 気になる記事を見つけても長文で読めない → AIが短く要約してくれる |

## 2. システム構成

```
[ブラウザ] → [Next.js（フロントエンド）]
                    │
                    ▼
            [Python API（Vercel Serverless Functions）]
            ├── スクレイピング（requests + BeautifulSoup）
            ├── LLM要約（anthropic / openai SDK）
            └── Slack投稿（Incoming Webhook）
                    │
                    ▼
              [Supabase（データベース + 認証）]
```

## 3. 機能要件

### 3.1 ユーザー認証

| ID | 機能 | 説明 |
|----|------|------|
| F-01 | 新規登録 | メールアドレス + パスワード（8文字以上）で登録。確認メール送信 |
| F-02 | ログイン | メール + パスワードでログイン → トップ画面へ遷移 |
| F-03 | パスワードリセット | ログイン画面から「パスワードを忘れた方はこちら」→ リセットメール送信 |
| F-04 | ログアウト | ログアウトボタンでセッション終了 → ログイン画面へ遷移 |
| F-05 | アカウント削除 | 設定画面から削除。確認ダイアログ表示後に実行 |

### 3.2 記事要約

| ID | 機能 | 説明 |
|----|------|------|
| F-06 | URL入力 | トップ画面のフォームにURLを貼り付ける |
| F-07 | 要約レベル選択 | 「簡単（3行）」「普通（5〜8行）」「詳しく（15行）」から選択。デフォルトは「普通」 |
| F-08 | 要約生成 | Python APIがURLをスクレイピング → LLMで要約生成 |
| F-09 | 要約結果表示 | 画面上に要約タイトル + 箇条書きの要約を表示 |
| F-10 | Slack自動投稿 | 要約完了時にSlack Incoming WebhookでSlackチャンネルに自動投稿 |
| F-11 | 重複URLチェック | 過去に要約済みのURLの場合、「再要約しますか？」と確認表示 |
| F-12 | ローディング表示 | 要約生成中は「記事の要約を生成しています...」とローディングアニメーション表示 |

### 3.3 要約履歴

| ID | 機能 | 説明 |
|----|------|------|
| F-13 | 履歴一覧 | 過去の要約を新しい順に一覧表示 |
| F-14 | 履歴詳細 | 一覧から1件選択 → 要約タイトル・本文・元URL・生成日時を表示 |
| F-15 | 履歴なし表示 | 履歴0件の場合「まだ要約履歴がありません」と表示 |

## 4. 非機能要件

| 項目 | 要件 |
|------|------|
| レスポンス | 要約生成は10秒以内に完了する |
| 認証 | Supabase Auth を使用（メール+パスワード認証） |
| セキュリティ | 未ログインユーザーはログイン画面以外アクセス不可 |
| レスポンシブ | スマホでも画面が崩れない |
| 対応言語 | 日本語のみ |
| LLM切り替え | 環境変数 `LLM_PROVIDER` で Claude / ChatGPT を切り替え可能 |

## 5. 技術スタック

| レイヤー | 技術 | 用途 |
|---------|------|------|
| フロントエンド | Next.js（TypeScript） | UI・ページ表示・ルーティング |
| 認証 | Supabase Auth | ユーザー登録・ログイン・セッション管理 |
| バックエンドAPI | Python（Vercel Serverless Functions） | スクレイピング・LLM連携・Slack投稿 |
| スクレイピング | requests + BeautifulSoup | URLからページ内容を抽出 |
| LLM | anthropic / openai（Python SDK） | 要約生成 |
| データベース | Supabase（PostgreSQL） | 要約履歴・ユーザー情報 |
| Slack連携 | Slack Incoming Webhook | 要約結果のSlack投稿 |
| デプロイ | Vercel | Next.js + Python API を一括デプロイ |

## 6. スコープ

### 今回やること
- ユーザー認証（登録・ログイン・パスワードリセット・削除）
- 記事URL入力 → AI要約 → Slackチャンネルに自動投稿
- 要約レベル選択（簡単/普通/詳しく）
- 要約履歴の保存・一覧・詳細表示
- 重複URLの確認フロー

### 今回やらないこと
- マイページ（プロフィール編集）→ 最低限の設定画面のみ
- おすすめ記事の自動推薦
- 複数言語対応
- PDF・動画の要約
