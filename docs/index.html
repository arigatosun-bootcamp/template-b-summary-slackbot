⚡ 主な機能

🔐 ユーザー認証

メール+パスワードで登録・ログイン。パスワードリセット・アカウント削除対応

📝 AI記事要約

URLを入力するだけでAIが記事を要約。3段階のレベル選択可能

💬 Slack自動投稿

要約完了時にSlackチャンネルへ自動投稿

📚 履歴管理

過去の要約を一覧・詳細表示。重複URLの検出

🤖 LLM切り替え

Claude と ChatGPT を環境変数で切り替え可能

📱 レスポンシブ

PC・タブレット・スマホすべてで快適に操作可能

4

5
Day5 — デプロイ + テスト + デモ準備
