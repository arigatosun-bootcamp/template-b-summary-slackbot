フロー全体マップ

@bot メンション受信 │ ├── URLあり │ ├── 要約済み？ → はい → 「再要約しますか？」 │ │ ├── はい → 要約実行 │ │ └── いいえ → 過去の要約表示 │ └── 未要約 → 要約実行 │ ├── 成功 → 要約結果をスレッド返信 → 履歴保存 │ └── 失敗 → エラーメッセージ返信 │ ├── 「履歴」 │ ├── 履歴あり → 最新5件表示 → 番号指定 → 詳細表示 │ └── 履歴なし → 「まだ要約履歴がありません」 │ ├── URLなし・その他 │ └── 「URLを追加してください」 │ └── Bot自身の投稿 → 無視
