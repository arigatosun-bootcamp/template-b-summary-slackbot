# 機能要件書 — Summary Slackbot

## F-01: 記事要約機能

### 概要
Botにメンション付きでURLを投稿すると、記事の内容を要約してスレッドで返信する。

### トリガー
- `@bot URL` — 普通の要約（デフォルト）
- `@bot URL 簡単` — 短い要約
- `@bot URL 詳しく` — 詳細な要約

### 処理フロー
1. ユーザーがBotにメンション付きでメッセージを投稿する
2. Botがメッセージ内のURLを検出する
3. Botがスレッドに「要約を生成中です...」と返信する
4. URLのページ内容をスクレイピングする（requests + BeautifulSoup）
5. 要約レベルを判定する（テキストに「簡単」「詳しく」があるかチェック）
6. LLMに要約を依頼する
7. 要約結果をスレッドに返信する（「生成中」メッセージを更新 or 新規投稿）
8. 要約結果をSupabaseに保存する

### 入力
| 項目 | 内容 |
|------|------|
| メッセージ形式 | `@bot URL [要約レベル]` |
| 要約レベル | `簡単` / （指定なし=普通） / `詳しく` |
| 対応URL | ニュース記事・ブログ記事（HTML） |

### 出力（要約結果のフォーマット）
```
📝 *記事タイトル*

• ポイント1
• ポイント2
• ポイント3
...

🔗 元記事: <URL>
```

### 要約レベルの目安
| レベル | 行数 | 説明 |
|--------|------|------|
| 簡単 | 3行程度 | 要点だけを簡潔に |
| 普通 | 5〜8行 | 主要なポイントをカバー |
| 詳しく | 15行程度 | 背景や詳細も含めて丁寧に |

### エラー処理
| ケース | Botの応答 |
|--------|----------|
| URLが含まれない | 「URLを追加してください」と返信 |
| 存在しないURL | 「このページは存在しません」と返信 |
| スクレイピング失敗 | 「このURLの内容を取得できませんでした」と返信 |
| LLM APIエラー | 「要約の生成に失敗しました。もう一度お試しください」と返信 |
| 要約レベルの指定ミス | デフォルト（普通）で要約し、指定方法を案内する |

### 重複URL処理
- 過去に要約済みのURLの場合、「過去に要約済みです。再要約しますか？」と確認する
- ユーザーが「はい」と答えたら再要約する
- ユーザーが「いいえ」と答えたら過去の要約を再表示する

## F-02: 履歴表示機能

### 概要
Botに「履歴」と伝えると、過去の要約タイトルを一覧表示する。

### トリガー
- `@bot 履歴`

### 処理フロー
1. ユーザーがBotに「履歴」とメンション付きで投稿する
2. SupabaseからSlackユーザーIDに紐づく要約履歴を取得する
3. 最新5件の要約タイトルを一覧でスレッドに返信する

### 出力フォーマット
```
📋 *要約履歴（最新5件）*

1. 記事タイトルA（2026-03-01）
2. 記事タイトルB（2026-02-28）
3. 記事タイトルC（2026-02-27）
4. 記事タイトルD（2026-02-26）
5. 記事タイトルE（2026-02-25）

読みたいタイトルの番号を教えてください。
```

### エラー処理
| ケース | Botの応答 |
|--------|----------|
| 履歴が0件 | 「まだ要約履歴がありません」と返信 |
| DB接続エラー | 「履歴の取得に失敗しました」と返信 |

## F-03: 履歴詳細表示機能

### 概要
履歴一覧から読みたいタイトルを伝えると、過去の要約を再表示する。

### トリガー
- 履歴表示後にタイトルの番号をメンション付きで投稿

### 処理フロー
1. ユーザーが番号を投稿する
2. 該当する要約をSupabaseから取得する
3. 要約結果をスレッドに返信する

### エラー処理
| ケース | Botの応答 |
|--------|----------|
| 存在しない番号 | 「その番号の履歴は見つかりませんでした」と返信 |

---

## F-04: 処理中メッセージ

### 概要
要約生成中はユーザーに処理中であることを伝える。

### 仕様
- URL受信後、即座にスレッドに「要約を生成中です...」と返信する
- 要約が完了したら、要約結果を新しいメッセージとしてスレッドに投稿する
- 30秒以上かかる場合、「生成に時間がかかっています。もう少しお待ちください」と追加メッセージを送る

---

## F-05: Bot自己防御

### 概要
Botが自分自身の投稿や無関係なメッセージに反応しないようにする。

### 仕様
- Bot自身の投稿には反応しない（`bot_id` チェック）
- Botへのメンションが含まれないメッセージには反応しない
- チャンネル・DMの両方で動作する

---

## F-06: LLM切り替え

### 概要
環境変数でClaude / ChatGPTを切り替える。

### 仕様
- 環境変数 `LLM_PROVIDER` の値で使用するLLMを決定する
  - `anthropic` → Claude API を使用
  - `openai` → OpenAI API を使用
- 未設定の場合はデフォルトで `anthropic` を使用する

---

## データ保存項目（Supabase）

### summaries テーブル

| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | 主キー |
| slack_user_id | text | SlackユーザーID |
| slack_channel_id | text | SlackチャンネルID |
| url | text | 要約対象のURL |
| title | text | 記事タイトル |
| summary | text | 要約結果 |
| summary_level | text | 要約レベル（簡単/普通/詳しく） |
| llm_provider | text | 使用したLLM（anthropic/openai） |
| created_at | timestamp | 作成日時 |
