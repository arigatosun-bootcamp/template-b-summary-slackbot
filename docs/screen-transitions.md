# 画面遷移図 — Summary Slackbot

## 画面一覧

| ID | 画面名 | URL | 認証 |
|----|--------|-----|------|
| S-01 | ログイン画面 | `/login` | 不要 |
| S-02 | 新規登録画面 | `/register` | 不要 |
| S-03 | パスワードリセット画面 | `/reset-password` | 不要 |

## 遷移パターン

### パターン1: 初回利用（新規登録）
```
ログイン画面 → 新規登録画面 → (メール認証) → ログイン画面 → トップ画面
```

### パターン2: 通常利用（要約）
```
ログイン画面 → トップ画面 → (URL入力・要約レベル選択) → 要約結果画面 → トップ画面
```

### パターン3: 履歴確認
```
トップ画面 → 履歴一覧画面 → 履歴詳細画面 → 履歴一覧画面
```

### パターン4: パスワード忘れ
```
ログイン画面 → パスワードリセット画面 → (メール送信) → ログイン画面
```

### パターン5: アカウント削除
```
トップ画面 → 設定画面 → (確認ダイアログ) → ログイン画面
```

### パターン6: 未ログインアクセス
```
任意のURL直接入力 → ログイン画面にリダイレクト
```

## ヘッダーナビゲーション（認証済み共通）

| 要素 | 遷移先 |
|------|--------|
| ロゴ / トップ | トップ画面 (S-04) |
| 履歴 | 履歴一覧画面 (S-06) |
| 設定 | 設定画面 (S-08) |
| ログアウト | ログイン画面 (S-01) |
