# 会話フロー図 — Summary Slackbot

Slack Bot型のため、画面遷移ではなく **Botとの会話フロー** を定義する。

---

## フロー1: 記事要約（正常系）

```
ユーザー: @bot https://example.com/article
    │
    ▼
Bot: 「要約を生成中です...」（スレッド返信）
    │
    ▼
Bot: 📝 *記事タイトル*（スレッド返信）
    │  • ポイント1
    │  • ポイント2
    │  • ポイント3
    │  🔗 元記事: URL
    ▼
  [完了 → 履歴に保存]
```

## フロー2: 要約レベル指定

```
ユーザー: @bot https://example.com/article 簡単
    │
    ▼
Bot: 「要約を生成中です...」
    │
    ▼
Bot: 📝 *記事タイトル*（3行程度の短い要約）

---

ユーザー: @bot https://example.com/article 詳しく
    │
    ▼
Bot: 「要約を生成中です...」
    │
    ▼
Bot: 📝 *記事タイトル*（15行程度の詳細な要約）
```

## フロー3: 重複URL確認

```
ユーザー: @bot https://example.com/article（過去に要約済みのURL）
    │
    ▼
Bot: 「このURLは過去に要約済みです。再要約しますか？」
    │
    ├── ユーザー: 「はい」
    │       │
    │       ▼
    │   Bot: 「要約を生成中です...」→ 新しい要約を返信
    │
    └── ユーザー: 「いいえ」
            │
            ▼
        Bot: 過去の要約を再表示
```

## フロー4: 履歴表示

```
ユーザー: @bot 履歴
    │
    ▼
Bot: 📋 *要約履歴（最新5件）*
    │  1. 記事タイトルA（2026-03-01）
    │  2. 記事タイトルB（2026-02-28）
    │  3. 記事タイトルC（2026-02-27）
    │  4. 記事タイトルD（2026-02-26）
    │  5. 記事タイトルE（2026-02-25）
    │
    │  読みたいタイトルの番号を教えてください。
    │
    ▼
ユーザー: 「2」
    │
    ▼
Bot: 📝 *記事タイトルB*（過去の要約を再表示）
```

## フロー5: 履歴が0件

```
ユーザー: @bot 履歴
    │
    ▼
Bot: 「まだ要約履歴がありません」
```

## フロー6: エラー系

### URLなしメッセージ
```
ユーザー: @bot こんにちは
    │
    ▼
Bot: 「URLを追加してください」
```

### 存在しないURL
```
ユーザー: @bot https://example.com/not-exist
    │
    ▼
Bot: 「要約を生成中です...」
    │
    ▼
Bot: 「このページは存在しません」
```

### スクレイピング失敗
```
ユーザー: @bot https://blocked-site.com/article
    │
    ▼
Bot: 「要約を生成中です...」
    │
    ▼
Bot: 「このURLの内容を取得できませんでした」
```

### LLM APIエラー
```
ユーザー: @bot https://example.com/article
    │
    ▼
Bot: 「要約を生成中です...」
    │
    ▼
Bot: 「要約の生成に失敗しました。もう一度お試しください」
```

### 応答遅延（30秒以上）
```
ユーザー: @bot https://example.com/long-article
    │
    ▼
Bot: 「要約を生成中です...」
    │
    ▼（30秒経過）
Bot: 「生成に時間がかかっています。もう少しお待ちください」
    │
    ▼
Bot: 📝 *記事タイトル*（要約結果）
```

---

## フロー全体マップ

```
@bot メンション受信
    │
    ├── URLあり
    │     ├── 要約済み？ → はい → 「再要約しますか？」
    │     │                         ├── はい → 要約実行
    │     │                         └── いいえ → 過去の要約表示
    │     └── 未要約 → 要約実行
    │           ├── 成功 → 要約結果をスレッド返信 → 履歴保存
    │           └── 失敗 → エラーメッセージ返信
    │
    ├── 「履歴」
    │     ├── 履歴あり → 最新5件表示 → 番号指定 → 詳細表示
    │     └── 履歴なし → 「まだ要約履歴がありません」
    │
    ├── URLなし・その他
    │     └── 「URLを追加してください」
    │
    └── Bot自身の投稿 → 無視
```
